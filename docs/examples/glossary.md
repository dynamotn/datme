The words this garden uses, and what they mean here.

## Backlink

A link seen from the note it points to.

**Evergreen note**: a note written to last, which keeps growing as you learn.

**Map of content**: a note that gathers links to others on one topic.

## Orphan

A note no other note links to.

**Stage**: how grown a note is, from seedling to evergreen.
