# Theme gallery

Every built-in style of datme, on the same note of this documentation
([Callouts and math](showcase/Callouts%20and%20math.md)), in light and dark mode.
Set one for the whole site with `appearance.style`, for a language, a season,
a folder, a tag or a growth stage with the other keys of `appearance`, or for
one note with `style:` (see [Look and
navigation](configuration.md#look-and-navigation)). Under `datme dev`, the 🎨
bar previews any page of your own garden in any of them.

The screenshots are made by `bun run screenshots styles`, which serves these
docs with `datme dev` and opens the note with `?style=` for each style.
