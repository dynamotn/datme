# datme documentation

datme publishes an Obsidian vault as a digital garden. These pages go from a
first preview to every setting there is. If you're new, start at the top.

1. [Getting started](getting-started.md): from a vault to a site online, step by step.
2. [Writing notes](writing.md): the Obsidian syntax datme understands, frontmatter, citations, series and multilingual notes.
3. [Page layouts](layouts.md): a page made for what a note holds, from a résumé to a shelf of books, with the [layouts of a note's own text](layouts-text.md) and the [collections](collections.md).
4. [Plugins](plugins.md): Dataview, Tasks, search queries, Canvas, Bases, Excalidraw, Marp, Kanban, Charts and flashcards.
5. [Privacy](privacy.md): what gets published and what never does, drafts, schedules, passwords and locked parts.
6. [The reader's side](reading.md): search, graph, keyboard shortcuts, reading preferences, offline reading.
7. [Configuration](configuration.md): every key of `datme.yaml`.
8. [Command line](cli.md): `dev`, `build`, `preview`, `check`, `deploy`, `export`, `init`, `migrate`.
9. [Deploying](deploying.md): GitHub, GitLab, Netlify, Cloudflare or any static host.
10. [Coming from another publisher](migrating.md): Obsidian Publish, the Digital Garden plugin or Quartz, in one command.
11. [Extending](extending.md): your own stylesheet and markdown plugins, and a map of the code for contributors.
12. [Theme gallery](themes.md): every built-in style, in light and dark.

This documentation is itself a datme garden. The [Showcase](showcase/Showcase.md)
shows what datme does with real notes: callouts, a slide deck, flashcards, a
locked passage, a board, queries, a drawing and a canvas, and every
[page layout](layouts.md) has a live example of its own.
